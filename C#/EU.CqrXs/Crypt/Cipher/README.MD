# Cipher contains

## AesNet
	a direct implementation of Aes without Legion of Bouncy Castle

## CipherEnum 
   enumeration of all in that solution availible cipher encryption algorithms

## CipherMode2
	enum providing CipherModes CBC, CCM, CFB, CTS, EAX, ECB, GOFB

## CipherPipe 
   a multi maximum 8´staged encryption and decrption pipe

## CryptBounceCastle
	provides encryption / decryption for several algos with Legion of Bouncy-Castle Framework

## CryptHelper
   various methods to merge key and hash or
   generate a long enough keybyte array

## CryptParams
   default or needed parameters for all cipher algorithns

## Des3Net
	Provides 3Des without Legion of Bouncy-Castle Framework

## SecureCipherPipe 
   a multi maximum 8 reduced staged encryption and decrption pipe with 8 different secure hashes as keys

## ZenMatrix
	my own simplest possible symmetric block cipher, where values and position of bytes are mapped through ZenMatrix

## ZenMatrix2
	my own simplest possible 256 key- and blocksize symmetric block cipher,where values and position of bytes are mapped through ZenMatrix2
